# Chhota Don AI Studio
A frontend demo for an original-content video workflow.

## Run
Open `index.html` in a browser.

## Publish
Upload the three files (index.html, style.css, script.js) to a static hosting service.
For a real video generator, add a backend/video-rendering API and authentication.

## Important
This project does not and cannot guarantee that third-party copyrighted material becomes copyright-free through editing.
Use videos you own or are licensed/authorized to transform.
